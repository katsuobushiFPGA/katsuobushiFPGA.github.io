# TODOリストアプリ

Vue.js 3 + TypeScript + Tailwind CSS で作成したシンプルなTODOリストアプリケーションです。

## 🚀 デモ

https://yourusername.github.io/todo-app/

## ✨ 機能

- ✅ TODOの追加・削除・完了切り替え
- 💾 LocalStorageでデータ永続化
- 📊 進捗状況の可視化
- 🎨 目に優しいモダンなUI
- 📱 レスポンシブデザイン

## 🛠️ 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```

## 📦 技術スタック

- Vue.js 3 (Composition API)
- TypeScript
- Vite
- Tailwind CSS
- LocalStorage API
