🔔 Web Notifications API デモ

ブラウザのネイティブ通知機能を体験しよう

1. 通知の許可

Web通知を使用するには、まずユーザーの許可が必要です。

2. 基本的な通知

シンプルなタイトルとメッセージだけの通知を送信します。

3. カスタム通知

アイコンや画像、タグなどのオプションを設定した通知を送信します。

4. 遅延通知（タイマー）

指定した秒数後に通知を送信します。タブを切り替えて待ってみてください。
