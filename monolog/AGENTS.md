# AGENTS.md

このドキュメントは、**Monolog** プロジェクトに取り組む AI エージェントおよび開発者のためのコンテキストガイドです。

## プロジェクト概要
**Monolog** は、個人的なジャーナリング（日記）のために設計されたローカル・オフラインの Twitter クローンです。Twitter (X) の UX を模倣していますが、ブラウザストレージを使用して完全にオフラインで動作します。

## アーキテクチャ
*   **クライアントサイドのみ**: バックエンドサーバーはありません。すべてのロジックは Vue フロントエンドに存在します。
*   **ストレージ**: IndexedDB が信頼できる唯一の情報源であり、`Dexie.js` によって管理されます。
    *   **リアクティビティ**: アプリは Dexie の `liveQuery` を使用して、データベースが変更されたときに UI をリアクティブに更新します。

## データベーススキーマ (`src/db.ts`)
*   **テーブル**: `posts`
    *   `id` (number, auto-increment): 主キー
    *   `content` (string): 投稿のテキスト内容。
    *   `createdAt` (Date): タイムスタンプ。
    *   `parentId` (number | undefined): 返信の場合の親投稿 ID。
    *   `reactions` (Array): 絵文字リアクションのリスト。

## 主要コンポーネント
*   **`App.vue`**: メインレイアウト。2カラムグリッド（サイドバー + メインコンテンツ）を処理します。また、**ローカル通知**のロジック（1時間ごとの投稿リマインダー）と通知ON/OFFの状態管理（localStorage）も担当します。
*   **`DateSidebar.vue`**: アーカイブビューのために投稿を日付ごとに集計して表示します。
*   **`PostList.vue`**: メインのタイムライン。表示をフィルタリングするための `selectedDate` プロップを受け入れます。
*   **`PostItem.vue`**: 再帰的コンポーネント。投稿、そのリアクション、および子（返信）を表示します。相対時刻（例: "5分前"）は `setInterval` により1分ごとに自動更新されます。
*   **`PostInput.vue`**: 新しい投稿や返信を作成するための絵文字ピッカー付きテキストエリア。

## PWA & 通知機能
*   **PWA対応**: `vite-plugin-pwa` を使用し、オフライン動作とインストール（A2HS）をサポート。
*   **ローカル通知**: Service Worker ではなく、メインスレッドの `setInterval` と `Notification API` を使用して実装。
    *   **トリガー**: 最後の投稿から1時間が経過すると通知。
    *   **設定**: ヘッダーのベルアイコンでON/OFF切り替え可能。設定は `localStorage` に保存。

## デザインシステム
*   **Tailwind CSS**: すべてのスタイリングに使用。
*   **テーマ**: クリーンでモダンな外観のための Slate（グレーブルー）カラーパレット。
*   **アイコン**: `lucide-vue-next`。

## 今後の検討事項
*   **データのエクスポート/インポート**: データはローカルにあるため、バックアップのための JSON エクスポート/インポート機能が重要です（未実装）。
*   **画像サポート**: 現在はテキストのみ。IndexedDB に（Blob として）画像を保存することは将来の拡張機能となる可能性があります。
