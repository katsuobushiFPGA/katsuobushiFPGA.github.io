# Monolog

**Monolog** は、個人的なオフラインファーストのマイクロブログアプリケーションです。ブラウザ内に完全に保存される、あなたのプライベートな思考、日記、メモのための Twitter ライクなインターフェースを提供します。

## 特徴

*   **🔒 プライバシーファースト**: すべてのデータは IndexedDB (Dexie.js 経由) を使用してブラウザにローカル保存されます。サーバーには一切送信されません。
*   **📱 Twitter ライクな UX**: スレッド機能を備えた、馴染みのあるタイムラインインターフェース。
*   **💬 スレッド返信**: 自分の投稿に返信して、スレッドや思考の深掘りを作成できます。
*   **😊 豊かな表現**: 絵文字ピッカーと Slack 風の絵文字リアクションを内蔵。
*   **📅 アーカイブビュー**: サイドバーを使って過去の投稿を日付ごとに閲覧できます。
*   **⚡ PWA 対応**: デスクトップやモバイルにプログレッシブウェブアプリとしてインストール可能。

## 技術スタック

*   **フレームワーク**: Vue 3 (Composition API, `<script setup>`)
*   **言語**: TypeScript
*   **ビルドツール**: Vite
*   **スタイリング**: Tailwind CSS
*   **データベース**: Dexie.js (IndexedDB wrapper)
*   **アイコン**: Lucide Vue Next

## 始め方

### 前提条件

*   Node.js (最新の LTS 推奨)
*   npm

### インストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```
